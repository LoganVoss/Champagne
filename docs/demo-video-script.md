# Champagne demo video plan (under three minutes)

This is a recording script, not a submission. Aim for about 2:35 so the final
cut has room for a title card and a clean ending. Record in the ChatGPT
in-app browser or WebMCP-enabled Chrome, with the browser audio and microphone
voiceover captured clearly.

## Before recording

- Open the live URL in a fresh tab.
- Confirm the **Demo** button loads `Motorcycle` without a file picker and the
  two arrows switch among all five bundled tracks.
- Keep ChatGPT's site-tools drawer available but collapsed until the reveal.
- Use headphones or a clean monitor path; set the browser and system volume
  before capture.
- Have the prompt ready: “Give the motorcycle track warm low-end weight and
  punchy drums, keep the top smooth, and leave the vocal space open.”

## Shot-by-shot script

| Time | Screen action | Voiceover |
| --- | --- | --- |
| 0:00–0:12 | Title card, then Champagne home screen | “This is Champagne: agentic music mastering. It keeps the audio local while a person and an agent shape the same audible master.” |
| 0:12–0:28 | Click **Demo**, play Motorcycle, then use **Switch Demo Track** once | “Five demo tracks ship with the site, so anyone can hear the workflow without giving us a file.” |
| 0:28–0:48 | Open the tools drawer / “What ChatGPT can see” | “The page exposes typed WebMCP tools—not pixel guesses. ChatGPT can read a compact studio state without seeing PCM, waveform samples, filenames, or paths.” |
| 0:48–1:10 | Type the prepared brief into **Mastering Magic** and submit | “I can speak in musical language. Champagne pulls out every useful cue, combines bounded dimensions, names a custom style, and renders it in the browser.” |
| 1:10–1:32 | Let the gold loading bar finish; switch Original/Mastered and play a short A/B | “The result is immediately audible. I can compare the untouched track and the new take in place, then ask for another direction if the balance is not right.” |
| 1:32–1:55 | In ChatGPT, call `create_variations` or `refine_mastering_take`; show the new User Preset | “Now the agent is operating the same command bus. It can create contrasting takes or refine one dimension, while every version stays reversible and appears in User Presets.” |
| 1:55–2:12 | Call `stage_comparison`; play two takes and switch between them | “The human remains the listener and decision-maker. ChatGPT stages the comparison; I decide which one actually feels right.” |
| 2:12–2:28 | Ask ChatGPT to preserve the master, cut/fade the ends, set 75% speed, and download; show the controls update | “Cuts, fades, speed, and download are complete agent actions too. Because I only asked for edits, Champagne preserves the master instead of rendering a new one.” |
| 2:28–2:35 | End on the studio and privacy line | “That is Champagne: a private audio instrument that people and agents can play together.” |

## Editing checklist

- Keep the total cut below three minutes.
- Make at least one before/after moment audible, not just visual.
- Leave the WebMCP tool names legible for a second or two.
- Show the custom style name in User Presets, the speed slider moving, the
  targeted edits, and the explicitly requested download.
- Do not show local file paths, private emails, API tokens, or browser dev
  secrets.
- Add captions for the prompt and the two most important voiceover lines.
